# Artwork and attribution

The starting point was an AI-generated Elden Ring themed menu concept selected by the project owner. [concept.png](images/concept.png) preserves that approved composition.

The original [background-erdtree.png](../theme/background-erdtree.png) was produced by an image-editing model to remove the fake menu text and highlight. The title, subtitle, divider, and gold tree remain part of that image. Real GRUB renders the menu labels and selection state.

The current [background.png](../theme/background.png) replaces the tree with a Site of Grace, based on the project owner's supplied reference. It was created with the built-in image generation tool on 2026-10-14. The [exact editing prompt](grace-artwork-prompt.txt) records the composition and preserved elements. The native renderer bends the flame in this image and adds circling light; no game video or frames are used for animation.

The three alternate concepts were also created with the built-in image generation tool on 2026-10-14, using the Grace composition as a layout reference. Each directory contains its final `background.png` and exact `prompt.txt`: [Carian / Age of the Stars](../concepts/carian/), [Destined Death](../concepts/destined/), and [Farum Azula / Beyond Time](../concepts/farum/). These are original AI-generated fan interpretations, not extracted game assets. The C renderer adds each concept's light and particle animation over its static background.

[The Shattered Ring](../concepts/ring/background.png) is a separate user-supplied 1600×900 cover image, copied unchanged. Its [source note](../concepts/ring/SOURCE.txt) distinguishes it from the generated concepts. The native animation adds gold bloom and flowing particles at runtime; the original logo, landscape, figure and source pixels remain in the asset.

The UI pixmaps in `theme/` are generated by `build-theme.py`. The screenshots and video are captures of this project's real GRUB VM, not game footage.

## Background editing prompt

> Edit this approved Elden Ring GRUB menu artwork to prepare the static background for a working interactive menu. Preserve the entire composition, exact dark charcoal color and subtle paper texture, the ELDEN RING title, CHOOSE YOUR REALM subtitle, the thin horizontal gold divider and central ornament beneath the subtitle, and all intricate golden Erdtree / roots / castle linework on the right. Preserve their placements and the 16:9 aspect ratio.
>
> Change ONLY the left-hand menu area below the divider: completely remove the four menu labels “Linux”, “Windows”, “Advanced options”, “UEFI Firmware Settings”, and remove the whole rectangular gold selection highlight surrounding Linux, including its corner diamonds. Also remove the tiny bottom-left navigation hint text and arrows. Seamlessly fill these removed elements with the same quiet dark background texture. The cleared area must be empty so that real text and animated selection can be drawn by software. Do not add replacement labels or ornament. The title, subtitle, divider, and right half tree art must remain as close to identical as possible. No other changes.

Regenerating that prompt will not reproduce the exact pixels. Use the included background to reproduce this theme.
